# Гостер

Учебный сервис на Flask для оформления библиографических записей по ГОСТ.

## Нормативная база

- `ГОСТ Р 7.0.100-2018` - библиографическое описание.
- `ГОСТ Р 7.0.5-2008` - библиографическая ссылка.
- Для электронных ресурсов дополнительно учитывается оформление `URL` и `даты обращения`.

## Что умеет

- Ручной конструктор записи для книги, статьи и сайта.
- Автоматическая генерация результата без перезагрузки страницы.
- Умный разбор ссылки или списка ссылок.
- Два режима вывода: `ГОСТ / русский` и `English references`.
- Интеллектуальный модуль на локальной модели через `Ollama`.
- Резервный эвристический разбор, если локальная модель не ответила.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

После запуска приложение будет доступно по адресу `http://127.0.0.1:5000`.

## Подключение локальной модели

Приложение использует `.env` в корне проекта.

Пример:

```bash
OLLAMA_API_URL=http://localhost:11434/api/chat
OLLAMA_MODEL=qwen2.5:7b
```

Перед запуском приложения должна быть установлена и запущена `Ollama`, а модель должна быть скачана:

```bash
ollama pull qwen2.5:7b
ollama run qwen2.5:7b
```

## Идея второго модуля

Вторая вкладка отправляет ссылку или библиографическую строку в локальную модель `Qwen` через `Ollama`. Модель:

1. получает сырую ссылку или URL;
2. пытается выделить поля источника;
3. формирует готовую запись по ГОСТ;
4. дополнительно возвращает поля в JSON-структуре;
5. если модель ошиблась или недоступна, приложение собирает запись эвристически.

Такое решение хорошо подходит для ВКР: в проекте есть полноценный интеллектуальный модуль на генеративной модели и резервный алгоритмический режим.

## Ограничения

- Это учебная реализация, а не полный движок библиографической валидации.
- Качество зависит от содержания страницы, доступности метаданных и качества входной ссылки.
- Эвристический режим работает лучше всего на русскоязычных записях с привычной пунктуацией.
